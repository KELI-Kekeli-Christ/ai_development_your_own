Classifieur d’images Udacity : `train.py`, `predict.py` et `Image_Classifier_Project.ipynb`.

```bash
python train.py --data_dir <jeu> --arch <architecture> --learning_rate <taux> --hidden_units <n> --epochs <n> --checkpoint <fichier>
```

`--gpu` est optionnel. `predict.py` est le script de prédiction à côté.
