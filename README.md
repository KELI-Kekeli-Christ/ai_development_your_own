Udacity image classifier: `train.py`, `predict.py`, and `Image_Classifier_Project.ipynb`.

```bash
python train.py --data_dir <dataset> --arch <architecture> --learning_rate <rate> --hidden_units <n> --epochs <n> --checkpoint <file>
```

`--gpu` is optional. `predict.py` is the prediction script beside it.
