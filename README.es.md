Clasificador de imágenes de Udacity: `train.py`, `predict.py` y `Image_Classifier_Project.ipynb`.

```bash
python train.py --data_dir <datos> --arch <arquitectura> --learning_rate <tasa> --hidden_units <n> --epochs <n> --checkpoint <archivo>
```

`--gpu` es opcional. `predict.py` es el script de predicción que está al lado.
